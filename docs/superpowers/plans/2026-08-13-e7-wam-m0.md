```python
@dataclass(frozen=True)
class WAMConfig:
    hidden_dim: int = 512
    num_layers: int = 12
    num_heads: int = 8
    ffn_hidden: int = 1408          # SwiGLU intermediate (2/3 * 4h ≈ GELU-2048 equivalent)
    cond_dim: int = 256             # slim AdaLN MLP input
    vision_dim: int = 768           # V-JEPA H11 latent dim
    geo_dim: int = 8                # MT-VJ p_times_visibility_flat
    n_scene_tokens: int = 16        # per-horizon spatial tokens (4x4 pool of last time slice)
    n_geo_tokens: int = 2           # per-horizon geometry tokens (g_future, nu)
    horizons: tuple = (6, 24, 48)
    action_horizon: int = 48
    action_dim: int = 4
    qk_norm: bool = True
    use_swiglu: bool = True
    dropout: float = 0.0

@dataclass
class WAMSceneVelocity:
    latent: Tensor  # [B, 3, 16, 768] velocity in latent space
    geo: Tensor     # [B, 3, 2, 8]    velocity in geometry space

class JointWorldActionFlow(nn.Module):
    def __init__(self, config: WAMConfig): ...
    def num_params(self) -> int: ...  # sum(p.numel())
    def forward(self, *,
                action_condition: Tensor,          # [B, 48, 512] read-only
                va_layers: tuple,                  # tuple of n_va tensors [B, 16, 512], read-only
                spatial_tokens: Tensor,            # [B, 16, 768] current 4x4 pool of last time slice
                geo_tokens: Tensor,                # [B, 8] current p*vis flat
                noisy_actions: Tensor,             # [B, 48, 4] action path x_t
                noisy_scene_latents: Tensor,       # [B, 3, 16, 768] scene path x_t
                noisy_scene_geo: Tensor,           # [B, 3, 2, 8]
                flow_time: Tensor,                 # [B] in [0,1]
                ) -> tuple[Tensor, WAMSceneVelocity]
                # returns (action_residual_velocity [B,48,4], scene velocities)
```

**Design notes (from spec §3.1):**
- Token layout (102 generated): 48 action tokens + 3×16 latent + 3×2 geo. Type embeddings (action/space/geo) + per-group position embeddings (action index, 4×4 spatial index flattened 0..15, horizon id) — no RoPE.
- Action token init: `embed_x(noisy_actions)` [48,4→512] + `cond_proj(action_condition)` [48,512→512]; latent tokens: `embed_l(noisy_scene_latents)` [3,16,768→512]; geo tokens: `embed_g(noisy_scene_geo)` [3,2,8→512].
- Per layer i (0..11): RMSNorm pre-norm → AdaLN(scale,shift) → SA over 102 tokens (qk_norm on Q/K, attention logits in fp32: `q.float() @ k.float().transpose(...) * scale`) → gate₁ → RMSNorm → CA to `va_layers[va_idx]` (K/V `Linear(512→512, bias=False)`, `W_O` zero-init) → gate₂ → RMSNorm → FFN SwiGLU → gate₃. `va_idx = min(i * n_va // num_layers, n_va - 1)`.
- AdaLN: `t_emb = SiLU(Linear(256)(sinusoidal(flow_time)))`; per layer `Linear(256, 6*hidden)` zero-init (weight+bias zero), chunk 6 → scale1,shift1,gate1,scale2,shift2,gate2; `hidden = hidden + gate*h` pattern (copy style of `FlowMatchingHead` model.py:1615-1643 but slim input).
- Heads after last layer: action `RMSNorm → Linear(512, 4)` **zero-init**; per-horizon latent heads (3 separate `Linear(512, 768)` normal init) applied to the 16 latent tokens of that horizon; per-horizon geo heads (3 separate `Linear(512, 8)` normal init).
- No `eval()`-time randomness; deterministic on CPU.
